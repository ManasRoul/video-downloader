# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-10

### Added
- Initial release
- Background daemon with WebSocket server
- System tray integration
- GTK-based download dialog
- Browser extension for Chrome/Firefox
- Support for YouTube, Vimeo, and direct media URLs
- Configurable download settings
- Multiple format options (video and audio)
- Progress tracking during downloads
- Desktop notifications
- Automatic installation script
- Comprehensive documentation

### Features
- Detects media playback in browser
- Download videos in multiple qualities
- Extract audio from videos
- Choose save location
- System tray icon with status
- Settings dialog
- About dialog
- Auto-start on login (optional)

### Supported Formats
- Video: MP4, WebM, MKV
- Audio: MP3, M4A, OGG
- Quality: Best, 720p, 480p

### Browser Support
- Google Chrome
- Chromium
- Microsoft Edge
- Firefox
- Any Chromium-based browser
