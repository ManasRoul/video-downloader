# Contributing to Media Downloader

Thank you for your interest in contributing! Here are some guidelines.

## Development Setup

1. Fork and clone the repository
2. Install dependencies:
   ```bash
   pip3 install -r requirements.txt
   ```
3. Make your changes
4. Test thoroughly

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable names
- Add comments for complex logic
- Include docstrings for functions and classes

## Testing

Before submitting:

1. Test on Ubuntu 20.04 and 22.04 if possible
2. Test with different video sites (YouTube, Vimeo, etc.)
3. Test audio-only downloads
4. Test the browser extension in Chrome and Firefox
5. Check for memory leaks with long-running tests

## Pull Requests

1. Create a feature branch
2. Make your changes
3. Test thoroughly
4. Update documentation if needed
5. Submit a pull request with:
   - Clear description of changes
   - Why the change is needed
   - Any breaking changes

## Bug Reports

When reporting bugs, include:

- Ubuntu version
- Python version
- Browser and version
- Steps to reproduce
- Error messages from logs
- Expected vs actual behavior

## Feature Requests

Feel free to suggest new features! Include:

- Use case
- Why it's useful
- Proposed implementation (optional)

## Areas for Contribution

Some ideas:

- Support for more video sites
- Better error handling
- Download queue management
- Video format conversion
- Playlist support
- Dark theme
- Translations
- Better notifications
- Download history
- Bandwidth limiting

## Code of Conduct

- Be respectful
- Be constructive
- Help others
- Follow GitHub's community guidelines
